# 🔄 Files Are Not Syncing, or a Red X Appears

A red X beside a file means OneDrive hit a synchronization error.

## Fix

1. Check your internet connection.
2. Click the OneDrive cloud icon and read any error message.
3. Confirm syncing is not paused. See [3.4 Pause or Resume Sync](../README.md#34-pause-or-resume-sync).
4. Check the icon beside the file. See [3.3 Status Icons](../README.md#33-status-icons) for what each one means.
5. Check your OneDrive storage. If it is full, see [Storage Is Full](storage-full.md).
6. Confirm you have permission to the file and that its name has no unsupported characters.

> [!NOTE]
> The error message in the OneDrive window usually names the exact problem, so read it before trying other steps.
