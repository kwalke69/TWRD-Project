# 💻 Files Are Missing on Another Device

## Fix

1. Confirm both devices are online and use the same OneDrive account.
2. Wait for sync to finish on the original device. See [3.3 Status Icons](../README.md#33-status-icons) to check progress.
3. Make sure syncing is not paused on either device. See [3.4 Pause or Resume Sync](../README.md#34-pause-or-resume-sync).
4. Make sure the folder is selected to sync on the second device. See [3.5 Choose Which Folders Sync](../README.md#35-choose-which-folders-sync).
5. Refresh File Explorer on the second device, or check OneDrive online.

> [!TIP]
> If the file appears on OneDrive online, the problem is on the second device. If it doesn't, the first device hasn't finished uploading it.
