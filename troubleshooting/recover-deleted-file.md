# ♻️ Recover a Deleted File

## Fix

1. Open OneDrive in your browser and go to **Recycle bin**.
2. Select the file and click **Restore**.

> [!IMPORTANT]
> Recovery depends on account type, retention policies, and whether the file was permanently deleted.
