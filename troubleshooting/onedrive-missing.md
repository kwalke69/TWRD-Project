# 🔎 OneDrive Is Missing from File Explorer

You may not be signed in, or OneDrive may not be running or configured.

## Fix

Follow **[3.1 Sign In](../README.md#31-sign-in)** in the main guide, then reopen File Explorer and check the navigation pane.
