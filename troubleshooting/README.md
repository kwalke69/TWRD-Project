# 🛠️ Troubleshooting

Solutions to common Windows 11 File Explorer and OneDrive problems. [← Back to the main guide](../README.md)

> [!TIP]
> Start with the status icon next to your file. A red X means a sync error, and a blue cloud means the file is online-only.
